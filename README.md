# ✨ Story Time

30 bedtime stories with text-to-speech read-aloud and interactive quizzes for kids aged 3-7.

## Features

- 📖 30 stories across 5 weeks (classic tales retold)
- 🎙️ Emotion-aware text-to-speech (adjusts voice for drama, whispers, excitement)
- 🧠 3-question quiz after each story
- ⚙️ Customizable character names (saved between sessions)
- 📱 Works offline — single HTML file, no server needed
- 🍎 iPhone installable (Add to Home Screen)

## Usage

Open `index.html` in any browser, or visit:

👉 **https://YOUR-USERNAME.github.io/storytime/**

### Install on iPhone
1. Open the link in Safari
2. Tap Share → Add to Home Screen
3. Works offline after first load

## Tech

Zero dependencies. Single HTML file. Vanilla JS + Web Speech API + localStorage.
